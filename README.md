# site-video-generate

Polished product demo videos of any website, made entirely on this machine. Claude writes the script and the shot list. Everything after that is free, local software:

| Stage | Tool | Cost |
|---|---|---|
| Site mapping | `scout`: Playwright reads the page and finds brand colours, sections and working selectors | free |
| Voiceover | Kokoro-82M via `hyperframes tts` (or macOS `say`) | free, offline after a one-time model download |
| Screen recording | Playwright with a frozen page clock: one 2× screenshot per frame at exactly 30 fps | free |
| Motion | HyperFrames (HTML + GSAP), generated by `src/compose.ts` | free, Apache-2.0 |
| Sound effects | `audio/sfx/`, from the Pixabay set bundled with HyperFrames | free, no attribution needed |
| Music | `audio/music/` (one CC BY track included) | free, credit required |
| Render + loudness | HyperFrames render + FFmpeg `loudnorm` (−14 LUFS) | free |

## Setup (once)

```bash
brew install ffmpeg
npm install
npx playwright install chromium
python3 -m venv py/.venv && py/.venv/bin/pip install -r py/requirements.txt   # Kokoro voice
```

The first Kokoro run downloads a ~340 MB model into `~/.cache/hyperframes/tts`. Until that has finished, add `--engine say --voice Samantha` to use the built-in macOS voice instead.

## Make a video of any site

```bash
npm run demo -- scout https://linear.app                 # map the site → demos/linear.json starter
# edit demos/linear.json (or ask Claude: "/demo-video make a demo of linear.app")
npm run demo -- all demos/linear.json --quality draft    # voice → record → compose → check → render
open out/linear/linear.mp4
```

You can also run one step at a time: `voice`, `record`, `compose`, `check`, `render` (`--quality draft|standard|high`). [demos/linear.json](demos/linear.json) is a real-site example. [examples/lumen.json](examples/lumen.json) runs against a bundled local page.

To edit the result by hand in HyperFrames Studio:

```bash
cd out/linear/project && npx hyperframes preview
```

Re-running `compose` overwrites hand edits. After editing, use `render` only.

## Listing reels (vertical, for Instagram / TikTok)

```bash
npm run social -- reel https://www.vihara.ai/listing/703-59th-ave-capitol-heights --new   # → reels/<slug>.json
# edit the copy and pick photos (or ask Claude: "/listing-reel make a reel of <url>")
npm run social -- reel reels/703-59th-ave-capitol-heights.json                         # → out/<slug>/<slug>.mp4
```

The listing page supplies the photos, price, Vihara estimate, beds, baths, square footage and auction date, and the starter spec writes copy from them. Without `--new`, a URL goes straight to a finished reel (about a minute). Scenes: hook → value (estimate struck through, bid ticks down, "18% below estimate" badge) → tour (photo cuts + fact chips) → auction date → light end card with the logo. Burned-in word-by-word captions use local Whisper timing (a one-time ~150 MB model download). The schema is in [src/social/reel-spec.ts](src/social/reel-spec.ts) and the workflow in [.claude/skills/listing-reel/SKILL.md](.claude/skills/listing-reel/SKILL.md).

## Writing a spec

Schema: [src/spec.ts](src/spec.ts). Each scene has narration, an optional 2–4 word title, and the browser actions that show what the narration says:

- `hover` / `click` / `type` `{selector, text?, zoom?, callout?, spotlight?}`
  - `zoom`: camera punch-in (defaults: click 1.45, type 1.5, hover 1.3; `1` = none)
  - `callout`: a short bubble pointing at the element; it stays up long enough to read
  - `spotlight`: dims everything except the element; on by default for click and type, and whenever there's a callout
- `scrollTo` `{selector, offset?}` / `scroll` `{y}`: eased, trackpad-style
- `wait` `{seconds}`, `goto` `{url}`

Top-level options:
- `brand` (name, accent, ground, ink, font)
- `chrome: "light" | "dark"` for the browser frame
- `hide: [selectors]` for clutter
- `music`

Common cookie banners are declined or hidden automatically, and so are chat widgets. A selector that fails on the live site is skipped with a warning; it doesn't crash the run. The whole recording is one continuous browser session, so logins and other state carry across scenes. Local sites work too: `http://localhost:3000`, or `file://./page.html` (relative to the spec).

## What the composer does

- **3D window:** the recording swings in, in perspective, inside a browser frame with a soft brand glow. The background has slowly drifting light orbs that flow unbroken across cuts.
- **Camera:** eased punch-ins on each interaction, pans between nearby targets, zooms out before scrolls, and keeps zoomed shots inside the window.
- **Spotlight:** the frame dims through a rounded hole while a ring settles on the element.
- **Callouts:** bubbles placed in screen space where the element sits once the camera has settled.
- **Cursor:** a drawn cursor that follows the same eased curve as the real pointer and presses on click.
- **Transitions:** varied per scene (3D tilt, whip, zoom, blur swap), each with a whoosh. **Motion blur** is on for the whole film.
- **Text:** word-by-word lower thirds, an intro with an accent word and rule, and an outro with a CTA shine.
- **Sound:** clicks, typing, pops on callouts and whooshes on cuts, each peaking one frame after its picture.

For more, use the HyperFrames registry (shader transitions, kinetic type, stat cards): `npx hyperframes catalog --tag transition`.

## Known limits

- Recording takes 1–3 minutes on heavy sites, because every frame is a full 2× screenshot.
- Spotlights and callouts are placed from the element's position when the action runs. If the page moves under them afterwards, they drift.
- Animations driven by real time outside the page's JS clock (for example cross-origin iframes) aren't frame-stepped.
- One music track is included: `audio/music/wallpaper.mp3` (Kevin MacLeod, CC BY 4.0; credit it in the video description, see `audio/music/CREDITS.md`). Use it with `"music": "../audio/music/wallpaper.mp3"`, or add your own royalty-free track.

## Never used

HeyGen voices, music or cloud rendering; `hyperframes auth`, `publish`, `cloud`, `lambda`, `cloudrun`; `audio --quality best`; vision captioning in `capture`. These can cost money or need an account.
